# 🔐 Basic Flask Login Page

A simple login system built with **Python and Flask** as a beginner web development project.

This project demonstrates how Flask can handle form submissions, user sessions, redirects, and a basic protected dashboard.

## 🚀 Features

- Simple username and password login
- POST request handling with Flask
- Session-based authentication
- Protected welcome/dashboard page
- Logout functionality
- Automatic redirects after login and logout
- Basic HTML login interface

## 🛠️ Technologies Used

- Python
- Flask
- HTML
